# 课程数据目录

- `team/`：保存团队共同提交材料。
- `personal/`：保存个人作业材料，文件名应包含成员标识并避免覆盖他人内容。
- `install.sql`：用于空库的数据库初始化脚本。

在 MariaDB/MySQL 中创建一个使用 `utf8mb4` 的空数据库，选中它并导入 `install.sql`，然后将项目的本地数据库配置指向该库。脚本已包含 Yii Migration 历史和三个模块的后台权限。

赛事数据包含 48 支球队、1,248 名球员、16 座场馆、104 场比赛和 308 条进球。每条赛事记录的 `source_url` 保留了 FIFA 官方来源。开球时间以 UTC 保存，点球大战比分记在比赛的赛果补充字段中。

网站账号由部署人员在本地创建并激活，再用 `php yii rbac/assign-admin 用户ID 用户名` 分配管理员权限。

`.gitignore` 会忽略其他 SQL 导出和数据库备份，但明确允许提交 `data/install.sql`。
