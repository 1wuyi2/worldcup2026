# 模块 B：新闻资讯使用手册

作者：XPC

日期：2026-11-22

## 访问入口

当前本地启动端口对应以下地址；后续部署时替换主机与端口即可。

| 功能 | 本地地址 |
| --- | --- |
| 公开新闻列表 | `http://127.0.0.1:18080/index.php?r=news/index` |
| 后台文章管理 | `http://127.0.0.1:18081/index.php?r=news/index` |
| 后台分类管理 | `http://127.0.0.1:18081/index.php?r=news-category/index` |
| 后台标签管理 | `http://127.0.0.1:18081/index.php?r=news-tag/index` |

后台使用网站账号登录，需要 `manageNews` 权限。当前本地 XPC 账号已有共享 `admin` 角色，可直接管理新闻。前台、后台的登录会话彼此独立。

## 首次录入顺序

1. 进入后台分类管理，新增如“赛事动态”“球队资讯”的分类，状态选择“启用”。排序值越小越靠前。
2. 进入标签管理，新增显示名称及唯一标识，例如名称“世界杯”、标识 `world-cup`。标识仅使用小写字母、数字和连接符。
3. 进入文章管理，点击“新增文章”。填写标题、分类和正文，可填写摘要、来源名称及来源链接，并勾选一个或多个标签。
4. 首次可选择“草稿”保存，进入详情检查内容。正文按纯文本展示，换行保留；粘贴 HTML 会显示为文字。摘要留空时列表使用正文前 160 个字符。
5. 在详情点击“发布”并确认，或在编辑页将状态设为“已发布”后保存。系统自动记录发布时间。
6. 打开公开新闻列表，检查标题、正文、分类、标签和来源是否正确；分别尝试关键词搜索、分类筛选、标签筛选，以及组合筛选。

正式新闻应根据可核对的公开资料整理，填写来源名称和链接。若暂用模拟内容，应在标题或正文中明确标注“演示数据”。不要将无来源的模拟赛果写成真实新闻。

## 日常维护

- 编辑：修改已发布文章并保存后，前台立即显示修改后的内容，发布时间保持原值。
- 撤稿：在文章详情点击“撤稿”。文章保留在后台，前台列表和直接详情地址均不可见；重新发布时记录新的发布时间。
- 分类停用：在分类编辑页选择“停用”，该分类中的文章暂时隐藏。重新启用后，已发布文章恢复公开。
- 分类删除：有文章引用时拒绝删除；先修改或删除引用文章，或直接停用分类。
- 标签删除：删除标签及全部关联，文章保留；标签的筛选入口随之移除。
- 文章删除：永久删除该文章及其标签关联，分类和标签本身保留。
- 清空标签：编辑文章时取消所有勾选，保存即可。

## 建议验收顺序

1. 保存草稿，确认前台搜索不到且直接详情不可访问。
2. 发布文章，确认列表和详情出现，并能通过分类、标签、标题找到。
3. 修改正文和标签，确认前台同步更新。
4. 撤稿后确认前台消失，再重新发布。
5. 停用分类，确认其中文章隐藏；重新启用后恢复。
6. 使用普通账号进入后台新闻地址，应显示 403；退出登录后访问后台应跳转登录页。

## 常见情况

| 现象 | 处理 |
| --- | --- |
| 公共菜单暂时找不到新闻入口 | 使用上表直接地址；公共导航会在后续统一调整 |
| 前台暂无新闻 | 先创建启用分类，再录入并发布文章 |
| 已发布文章不显示 | 检查分类是否启用、文章是否被撤稿 |
| 发布提示分类不可用 | 选择启用分类，或先启用现有分类 |
| 标签保存失败 | 检查标识是否重复，或刷新后重新选择已存在的标签 |
| 后台 403 | 确认登录后台的是管理员账号，且已初始化 `manageNews` |
| 页面打不开、连接被拒绝 | 保持数据库及对应 PHP 服务运行；新闻功能无需重启服务 |

在当前 PHP 内置开发服务下，保存源代码后刷新页面即可。编写代码时无需关闭数据库或前后台服务。
