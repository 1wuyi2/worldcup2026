## 图示资源

`images/` 目录用于保存系统模块图、数据库 ER 图及业务流程图等设计文档配套资源。

## 后续文档

根据课程交付要求，后续补充实现文档、用户手册、部署文档及综合测试记录。

## 文档维护约定

- 需求文档记录项目功能范围及验收要求。
- 设计文档记录系统架构、数据库结构及业务实现方案。
- 测试记录应注明实际测试环境、执行过程和验证结果。
- 数据库设计应与 Migration 及最终数据库结构保持一致。
- 文档必须区分规划内容、实际实现和已验证结果，不得将未完成内容描述为已实现。
- 项目发生重要结构或业务调整时，应同步更新相关文档及图示。
